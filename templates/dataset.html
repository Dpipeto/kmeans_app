Preparación de Datos
Proceso de Limpieza y Normalización
1. Valores nulos: El dataset no presenta valores nulos. Se validó que todas las columnas tuvieran valores dentro de rangos razonables.
2. Outliers: Se aplicó clip() durante la generación para garantizar rangos coherentes con la realidad (edad 18–75, ingresos > 700 000 COP, etc.).
3. Normalización (StandardScaler): Dado que las variables tienen escalas muy distintas (ingresos en millones vs frecuencia en unidades), se aplicó estandarización Z-score para que ninguna variable domine el cálculo de distancias.
4. Selección de variables: Se excluyó cliente_id por ser identificador no numérico. Las 6 variables restantes tienen correlación suficiente con el comportamiento de compra.
Código de Preparación
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv('clientes.csv')

# Seleccionar features numéricas
features = ['edad', 'ingreso_mensual', 'gasto_mensual',
            'frecuencia_compras', 'antiguedad_meses', 'num_productos']
X = df[features]

# Normalizar con Z-score
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
